# Screenshot UI Sawala

Kumpulan screenshot mencakup landing page, login dan pendaftaran, seluruh bagian admin, serta seluruh halaman pengguna yang tersedia melalui navigasi. Bagian pengguna meliputi beranda, kelas Bahasa Sunda dan Aksara Sunda, ruang belajar per modul, kumpulan aksara, daftar dan pengerjaan latihan, daftar dan pengerjaan kuis, Tutor AI, progres, ulangan, ulasan jawaban, materi tersimpan, umpan balik, profil, dan keamanan akun.

Semua gambar diambil pada viewport desktop 1440 × 900 dengan konten diperkecil sekitar 90% dan scrollbar disembunyikan. Screenshot menggunakan ukuran viewport agar tampilan tiap halaman konsisten. Nama file admin berakhiran `_admin`, sedangkan halaman pengguna berakhiran `_pengguna`.

Buka `index.html` untuk galeri, atau lihat berkas JPG satu per satu. ZIP `screenshots/sawala-ui-screenshots.zip` berisi gambar, galeri, dan README ini.
